## 1. 页面结构

### 1.1 整体布局

桌面端采用左右分栏，聊天区与分析区约 1:1 等宽：

```
┌─────────────────────────────────────────────────────────────┐
│  会话标题栏                                                    │
│  [新会话] [会话列表 ▼]                           [用户头像]  │
├──────────────────────────┬──────────────────────────────────┤
│      聊天区 1fr           │         分析区 1fr                │
│                          │                                  │
│  ┌────────────────────┐  │  ┌────────────────────────────┐  │
│  │ 消息列表            │  │  │ 标签页：                   │  │
│  │  （可滚动）          │  │  │  话题 │ Agent │ 快照 │ 调用│  │
│  │                    │  │  │                            │  │
│  │  [用户消息]         │  │  │  ┌──────────────────────┐  │  │
│  │  [Agent A 回复]     │  │  │  │ 内容面板             │  │  │
│  │  [Agent B 回复]     │  │  │  │                      │  │  │
│  │  [生成指示器...]    │  │  │  │                      │  │  │
│  │                    │  │  │  └──────────────────────┘  │  │
│  └────────────────────┘  │  │                            │  │
│  ┌────────────────────┐  │  └────────────────────────────┘  │
│  │ 输入区域            │  │                                  │
│  │ [ 输入消息...] [发送] │  │      （首版不可折叠）             │
│  └────────────────────┘  │                                  │
├──────────────────────────┴──────────────────────────────────┤
│  状态栏：运行状态 | 消息计数 | Token 计数 | 停止按钮            │
└─────────────────────────────────────────────────────────────┘
```

- 分栏宽度比例：1:1，分析区最小宽度 360px。
- 聊天区在分析区加载完成前不应空白等待；二者异步独立渲染。
- 首版两区均不可折叠或隐藏；后续阶段可根据需要增加可折叠性。

### 1.2 窄屏适配（< 900px）

```
┌────────────────────────────┐
│  会话标题栏                  │
├────────────────────────────┤
│  标签切换：[聊天] [分析]      │
├────────────────────────────┤
│                            │
│  当前激活区域全宽            │
│                            │
├────────────────────────────┤
│  状态栏                     │
└────────────────────────────┘
```

- 900px 断点以下切换为上下或标签页切换布局。
- 标签切换不丢失当前区域滚动位置。
- 分析区标签页在窄屏下仍保持内部标签导航。

## 2. 聊天区组件与状态

### 2.1 消息列表

#### 2.1.1 消息气泡规范

| 属性 | 值 |
| --- | --- |
| 用户消息 | 右对齐，纯色背景（如 `--msg-user-bg`） |
| Agent 消息 | 左对齐，浅色背景（如 `--msg-agent-bg`），顶部显示 Agent 名称和头像 |
| 用户名 | 固定显示"我" |
| Agent 名 | 从参与者配置读取 display_name |
| 时间戳 | 鼠标悬停/聚焦时 tooltip 显示 `HH:mm:ss`；不始终可见 |
| 消息连续归属 | 同一发送者的连续消息不重复显示头像和名称 |

#### 2.1.2 消息类型与视觉区分

| 类型 | 视觉特征 | 说明 |
| --- | --- | --- |
| 用户文本 | 右对齐气泡 | 普通用户发送 |
| Agent 文本 | 左对齐气泡 + 名称头像 | Agent 回复的消息 |
| 生成中指示器 | 左对齐 + 闪烁光标/脉冲点 | Agent 正在生成回复 |
| 系统消息 | 居中，较小字号，弱对比色 | 运行开始、停止、错误通知 |
| 已停止标记 | 气泡间分割线 + 文本 | 标记自动接力终点 |

#### 2.1.3 状态

**空状态**
- 新会话无消息时显示占位提示：
  - 标题："开始群聊实验"
  - 副文本："发送一条消息，观察两个 Agent 如何参与对话。"
  - 不显示空消息列表骨架。

**加载状态**
- 历史会话加载时显示消息列表骨架屏：3～5 条灰色条，模拟消息分布。
- SSE 重连补齐时不显示骨架，直接在底部追加事件。

**正常滚动**
- 新消息到达时自动滚动到底部。
- 用户主动向上滚动阅读历史时暂停自动滚动，底部显示"新消息"按钮。
- 点击"新消息"或用户发送消息时恢复自动滚动。

**错误状态**
- 消息发送失败：在失败消息旁显示红色错误图标和"发送失败"文字，保留消息内容。
- 提供"重试"和"删除"操作。
- 网络断连时在输入区上方显示横幅："连接已断开，正在重连…"

### 2.2 生成指示器

当对话运行中、至少一个 Agent 被选中生成回复时，在消息列表底部显示：

```
┌────────────────────────────┐
│  Agent A 正在输入…   ●●●   │
└────────────────────────────┘
```

- 每个正在生成的 Agent 显示一行。
- 动画使用三个脉冲点，不模拟逐词打字效果。
- 生成完成时指示器平滑消失并显示完整消息气泡。
- 两个 Agent 同时生成时（首版不会发生，但规范预留）：分别显示两行。

### 2.3 输入区域

#### 2.3.1 组成

- 多行文本框（`<textarea>`），支持 Shift+Enter 换行、Enter 发送。
- 发送按钮，位于文本框右下角或右侧。
- 文本框随内容自动增高，最大 6 行，超出后滚动。

#### 2.3.2 状态

| 状态 | 行为 |
| --- | --- |
| 空闲 | 文本框可输入，发送按钮可点击 |
| 运行中 | 文本框禁用（`disabled`），发送按钮禁用，显示"等待自动接力结束…" |
| 发送中 | 按钮显示 loading 旋转，短暂禁用去重（由幂等键保证） |
| 空输入 | 按钮禁用；输入非空白字符后启用 |
| 停止请求中 | 文本框保持禁用，状态栏显示"正在停止…" |
| 错误 | 文本框恢复可用，允许用户重新发送 |

运行中状态下，用户仍可选中并复制历史消息。

### 2.4 会话标题与列表

- 当前会话标题：左上角显示，默认"群聊实验"或用户自定义标题。
- 会话切换：提供返回会话列表的入口；首版支持单会话焦点但保留切换路径。
- 会话删除：提供删除当前会话的入口，触发二次确认对话框。

## 3. 分析区组件与状态

### 3.1 标签页结构

分析区使用水平标签切换四个子面板：

```
[ 话题 ] [ Agent ] [ 快照 ] [ 调用 ]
```

- 标签当前激活态使用底部边框或下划线指示。
- 标签数量固定，不随上下文增减。
- 每个标签页携带未读高亮指示器（仅在自动接力运行期间刷新）。

### 3.2 话题面板

#### 3.2.1 内容

展示当前会话的所有话题链及其状态：

- 话题列表：每个话题一行，显示标题、状态标签（active/inactive）、消息数。
- active 话题置顶显示，使用高亮背景色。
- inactive 话题按最后更新时间倒序排列。
- 选中话题后展开详情：
  - 创建和状态变化时间线（来自 `topic_transitions`）。
  - 关联的消息列表（来自 `message_topic_links`）。
  - 当前摘要内容（如存在）。

#### 3.2.2 状态

| 状态 | 表现 |
| --- | --- |
| 无话题 | "尚无话题，发送一条消息开始对话。" |
| 单话题 active | 列表显示一个 active 话题 |
| A → B 切换 | active 从 A 变为 B，A 显示 inactive 标签 |
| A → B → A | B inactive 后 A 重新激活，时间线展示完整转换链 |
| 运行中更新 | 新话题或状态变化实时追加，不重置滚动位置 |

### 3.3 Agent 面板

#### 3.3.1 内容

展示每个 Agent 的话题索引和决策历史：

- Agent 选择：两个头像标签切换。
- 话题索引列表：每个索引行显示话题标题、salience/role_affinity/familiarity 三个分数（0～1 条形图或数值）、最后活跃时间。
- 最近决策列表：按时间倒序显示该 Agent 的参与决策。

#### 3.3.2 决策条目

每条决策展示：

- 触发消息摘要（前 60 字符 + "…"）。
- 参与分数与阈值比较的条形图。
- 结果标签：`selected`（绿色）、`eligible_not_selected`（黄色）、`silent`（灰色）、`ineligible`（红色）。
- 回复意图标签（如 `answer`、`ask`、`add`、`challenge`、`continue`、`none`）。
- 维度明细：relevance、direct_address、novelty、role_fit、open_question、repetition_risk 的分数（紧凑行）。
- 原因码标签列表。
- 点击展开完整决策 JSON。

首版不显示模型内部思维链；所有原因来自结构化维度和原因码。

### 3.4 快照面板

#### 3.4.1 内容

展示选中消息/Agent 对的实际上下文快照：

- 触发消息选择器：下拉选择最近运行的消息。
- Agent 切换：两个 Agent 标签。
- 快照条目列表：按 ordinal 排序，每行显示：
  - 条目类型图标（system/message/topic_summary/instruction）。
  - 引用消息或摘要的摘要文本（过长截断，可展开）。
  - 估算 Token 数。
  - 包含原因标签。

#### 3.4.2 状态

| 状态 | 表现 |
| --- | --- |
| 无运行 | "尚无上下文快照。" |
| 运行中 | 最新快照随 `context.captured` 事件持续更新 |
| 选择无效 | 选择尚未有决策的消息时显示"该消息尚未触发 Agent 决策" |
| Token 超限 | 快照条目中标记 `context_budget_exceeded` 条目为错误状态 |

### 3.5 模型调用面板

#### 3.5.1 内容

展示模型调用的时序与性能：

- 调用列表：按时间倒序，每行显示：
  - 用途标签（topic_route/decision/generation/summary）。
  - Agent 名称（如适用）。
  - 供应商和模型名。
  - 状态（success/error/partial）。
  - 耗时（ms）。
  - 输入/输出 Token 数。
  - 估算成本（$μ$，带版本标签）。
- 选中后展开详情：
  - 请求 ID 和时间戳。
  - 错误类别和详情（如失败）。
  - 完整的 Token 明细。

### 3.6 分析区与消息的联动

- 右键点击聊天区消息，菜单中包含"在分析区查看"。
- 点击后分析区自动切换到相关面板并高亮对应条目：
  - 用户消息：切换到话题面板，高亮对应话题。
  - Agent 消息：切换到 Agent 面板，高亮对应 Agent 的决策。
- 分析区面板中的消息引用可点击，点击后聊天区滚动到对应消息并短暂高亮。
- 消息与分析的联动只涉及滚动和高亮，不改变数据或状态。

## 4. 核心交互流程

### 4.1 发送消息 → 自动接力

```
用户输入 → 点击发送 → POST /messages → 202 {message_id, run_id}
                                 │
                         ┌───────┴───────┐
                         │               │
                   同步响应成功      同步响应失败
                         │               │
                   消息气泡立即        按钮恢复，显示
                   出现在列表         错误状态，保留输入
                   （灰色/待确认）          │
                         │               └── 用户重试
                   接力开始 ───────────────→ SSE 事件流
                         │
                    ┌────┴────┐
                    │         │
                message.created → 更新消息状态为已确认
                topic.routed → 话题面板更新
                decision.completed → Agent 面板更新
                speaker.selected → 显示选中 Agent
                generation.started → 生成指示器出现
                generation.completed → 消息气泡 + 指示器消失
                run.completed → 状态栏更新，文本框恢复
                    │         │
                    └─────────┘
```

**收到 202 但 SSE 断连**：消息已落库。页面以历史查询恢复到最新状态。不自动重试发送。

### 4.2 A → B → A 话题切换

```
用户消息 M1: "我们今天聊聊 Python 的异步编程"
  → 聊天区显示 M1
  → 话题面板：话题 A 创建，active
  → Agent 面板：两个 Agent 的决策结果

Agent A 回复 M2 关于 asyncio
  → 聊天区显示 M2
  → 话题面板：话题 A 继续

用户消息 M3: "对了，你们知道最近有什么好电影吗？"
  → 聊天区显示 M3
  → 话题面板：话题 B 创建，A 变为 inactive，B active
  → 话题 A 显示"被打岔"标签
  → 时间线：显示 M3 触发的 create 转换

Agent B 回复 M4 推荐电影
  → 聊天区显示 M4

用户消息 M5: "回到刚才的异步问题，协程的取消机制怎么处理？"
  → 聊天区显示 M5
  → 话题面板：话题 A 重新激活，B 变为 inactive
  → 时间线：显示从 A→B→A 的完整转换链
  → 快照面板：Agent A 的快照包含话题 A 的摘要
```

### 4.3 停止接力

```
用户点击停止按钮 / POST /runs/{id}/stop
  → 按钮变为"正在停止…"（禁用状态）
  → SSE: run.stop_requested 事件
  → 输入区保持禁用
  → 已有消息完整显示
  → SSE: run.stopped { stop_reason: "user_stop" }
  → 状态栏更新
  → 文本框恢复可用
  → 停止标记出现在最后一条消息下方

停止后才收到的迟到生成结果：不显示。
首版不提供"恢复已停止接力"功能。
```

### 4.4 错误场景

**模型调用超时/失败**
- SSE 推送 `run.failed { stop_reason: "provider_error" }`。
- 聊天区：最后一条生成指示器消失，显示系统消息"Agent A 回复失败"。
- 分析区：模型调用面板显示错误状态和错误详情。
- 输入区恢复可用，允许用户重新发送。

**结构化输出无效**
- SSE 推送 `run.failed { stop_reason: "invalid_output" }`（重试后仍失败）。
- 聊天区：系统消息"Agent 响应格式异常，本轮自动接力已结束"。
- 分析区：决策条目标记 `invalid_model_output`。

**服务重启**
- 启动时非终态运行标记为 `failed/server_restart`。
- 聊天区在消息列表顶部（或对应运行终点）显示系统消息"服务重启，接力已安全终止"。
- 已提交消息完整可读，不受影响。

**SSE 断线重连**
- 页面自动按 `Last-Event-ID` 重新发起 SSE 连接。
- 补齐期间 UI 不显示错误，显示一个较小的"正在同步…"指示。
- 补齐完成后指示消失。
- 若补齐检测到 seq 不连续，自动调用 `/conversations/{id}/messages` 或快照接口恢复。

## 5. 状态栏

位于页面底部，横跨两区，显示当前运行状态信息。

### 5.1 组成

```
[ 状态指示器 ] [ 消息数 ] [ 轮数 ] [ Token ] [ ▸ 停止按钮 ]
```

| 元素 | 内容 |
| --- | --- |
| 状态指示器 | 圆点 + 文本：空闲（灰色）/ 运行中（绿色，脉冲）/ 停止中（黄色）/ 错误（红色） |
| 消息数 | "消息：N（Agent: M）" |
| 轮数 | "轮次：N / 上限" |
| Token | "Token：N / 上限" |
| 停止按钮 | 仅在运行中可见，圆角实心按钮，带停止图标 |

### 5.2 状态对应

| 运行状态 | 指示器 | 停止按钮 | 文本框 |
| --- | --- | --- | --- |
| 无运行/空闲 | 灰色 ● 空闲 | 隐藏 | 可用 |
| 接力中 | 绿色 ● 运行中 | 可用 | 禁用 |
| 停止请求已提交 | 黄色 ● 正在停止 | 禁用（"停止中"） | 禁用 |
| 停止完成 | 灰色 ● 已停止（3 秒后变空闲） | 隐藏 | 可用 |
| 失败 | 红色 ● 失败 | 隐藏 | 可用 |
| 上限到达 | 灰色 ● 已结束 | 隐藏 | 可用 |

## 6. 消息—分析联动

### 6.1 事实来源映射（分析区使用）

| 聊天区元素 | 分析区对应 | SSE 事件 |
| --- | --- | --- |
| 用户消息 | 话题面板（话题创建/继续/切换） | `message.created`、`topic.routed` |
| Agent 消息 | Agent 面板（决策详情） | `message.created`、`decision.completed` |
| 生成指示器 | Agent 面板（generation.started） | `generation.started` |
| 停止标记 | 运行状态（stop_reason） | `run.stop_requested`、`run.stopped` |
| 系统错误消息 | 模型调用面板（error） | `run.failed` |

### 6.2 信息架构一致性

- 两区展示同一事实的两面，不出现矛盾。
- 聊天区的状态只来自 SSE 事件，不来自前端超时猜测。
- 分析区的数据只来自查询 API，不来自 SSE。
- 聊天区消息的 sequence_no 与分析区决策的 trigger_message_id 应一一对应。

### 6.3 时间同步

- 所有时间戳使用 UTC ISO 8601 存储和传输。
- 前端在渲染时转换为本地时间。
- 聊天区消息按 `created_at` 排序。
- 分析区事件按事件时间排序，与聊天区顺序一致。

## 7. 响应式设计规则

### 7.1 断点

| 断点 | 布局 | 说明 |
| --- | --- | --- |
| ≥ 1200px | 左右分栏，各 1fr | 宽屏桌面 |
| 900px ～ 1199px | 左右分栏，聊天区 1fr、分析区 1fr | 标准桌面，翻折本 |
| < 900px | 标签页切换 | 平板竖屏、小窗口 |
| < 480px | 标签页切换 + 紧凑样式 | 手机竖屏 |

### 7.2 窄屏适配规则

- 900px 以下使用标签页在聊天/分析间切换。
- 聊天标签为默认激活。
- 标签切换时保留各区域滚动位置和展开状态。
- 输入区域始终可见（不在分析标签页下隐藏）。
- 消息气泡在窄屏下缩短最大宽度（从 70% 变为 85%）。
- Agent 名称和头像缩小但保留。
- 状态栏在 < 480px 下折叠为仅显示状态指示器和停止按钮，详情通过点击展开。

### 7.3 字体与缩放

- 基础字号：16px（移动端）/ 15px。
- 支持浏览器默认缩放（Ctrl+/Ctrl-）。
- 禁止使用 `user-scalable=no` 或 `maximum-scale=1`。
- 所有间距使用相对单位（rem），不使用固定 px 间距。

## 8. 可访问性要求

### 8.1 键盘操作

| 操作 | 按键 | 说明 |
| --- | --- | --- |
| 发送消息 | Enter（文本框聚焦时） | 同单击发送按钮 |
| 换行 | Shift+Enter | 文本框内 |
| 停止接力 | Ctrl+Shift+S（全局） | 等效点击停止按钮 |

| 切换聊天/分析（窄屏） | Tab 进入标签组后 ← → | 标准标签导航 |

| 展开分析区详情 | Enter 或 Space | 选中条目 |

### 8.2 焦点管理

- 发送消息后焦点回到文本框。
- 停止接力后焦点回到文本框。
- 关闭对话框后焦点回到触发元素。
- SSE 事件更新的区域不抢走当前焦点。
- 新消息到达时若用户未在阅读历史，通过 `aria-live="polite"` 区域宣布。

### 8.3 ARIA

| 区域 | ARIA 属性 |
| --- | --- |

### 8.4 色彩与对比度

- 所有文本与背景对比度不低于 WCAG AA（4.5:1 常规文本、3:1 大文本）。
- 状态指示器不仅靠颜色区分，同时附加文本标签。
- Agent 角色颜色区分提供至少两种替代方案（颜色 + 图标/名称位置）。
- 分析区的分数条形图同时显示数值。

## 9. 文案规范

### 9.1 中文约定

- 全文使用简体中文。
- 数字与英文之间加空格（"共 5 条消息"）。
- 标点使用全角（，。！？）；英文/数字/代码使用半角。
- 产品名称 "pal-chat" 保持小写+连字符。

### 9.2 标准文案

| 场景 | 文案 |
| --- | --- |
| 空消息列表 | "开始群聊实验" / "发送一条消息，观察两个 Agent 如何参与对话。" |
| 空话题面板 | "尚无话题，发送一条消息开始对话。" |
| 空 Agent 面板 | "尚无决策数据。" |
| 空快照面板 | "尚无上下文快照。" |
| 空调用面板 | "尚无模型调用记录。" |
| 运行中禁用提示 | "等待自动接力结束…" |
| 停止中 | "正在停止…" |
| 停止完成 | "已停止"（短暂显示后消失） |
| 上限到达 | "自动接力已结束（达到上限）" |
| 无人回应 | "无人需要回应，自动接力已结束" |
| 发送失败 | "发送失败" + [重试] [删除] |
| 服务重启 | "服务重启，接力已安全终止" |
| 模型错误 | "{Agent} 回复失败" |
| 输出格式异常 | "Agent 响应格式异常，本轮自动接力已结束" |
| 断连中 | "连接已断开，正在重连…" |
| 同步中 | "正在同步…" |
| 删除会话确认 | "确定删除此会话？此操作不可撤销。" |

### 9.3 决策结果标签

| 结果 | 标签 | 色值（例） | 说明 |
| --- | --- | --- | --- |
| `selected` | 选中发言 | 绿色 | Agent 被选中生成回复 |
| `eligible_not_selected` | 想回应但未选中 | 黄色 | Agent 意愿 ≥ 阈值但未获发言权 |
| `silent` | 沉默 | 灰色 | Agent 意愿 < 阈值，未想回应 |
| `ineligible` | 不具资格 | 红色 | 硬规则排除（连续上限、预算不足等） |

## 10. 状态穷举矩阵

### 10.1 全局应用状态

| # | 状态 | 聊天区 | 输入区 | 停止按钮 | 分析区 | 触发条件 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | 空闲 | 显示历史消息 | 可用 | 隐藏 | 显示历史分析 | 无运行 / 运行已完成 |
| 2 | 接力中 | 消息追加 + 生成指示器 | 禁用 | 可用 | 随 SSE 实时更新 | `run.status = running` |
| 3 | 停止请求中 | 正常显示 | 禁用 | 禁用（"停止中"） | 停止更新 | `POST /stop` 已提交 |
| 4 | 停止完成 | 追加停止标记 | 立即可用 | 隐藏 | 显示最终状态 | `run.stopped` |
| 5 | 失败 | 系统错误消息 | 可用 | 隐藏 | 显示错误详情 | `run.failed` |
| 6 | 断连 | 无变化 | 断连横幅 | 隐藏/禁用 | 无变化 | SSE 连接断开 |
| 7 | 同步中 | 无变化 | 禁用 | 禁用 | 仅展示已有数据 | SSE 重连补齐中 |
| 8 | 只读历史 | 不可发送 | 隐藏/禁用 | 隐藏 | 完整可浏览 | 查看已完成的历史运行 |

### 10.2 权限与禁用

首版为本地实验台，无多用户权限体系。所有功能对当前用户完全可用。以下情况为自然禁用而非权限限制：

- 接力运行中文本框禁用（并发防护）。
- 停止请求已提交时停止按钮禁用（幂等）。
- 空输入时发送按钮禁用（前置条件）。
- 正在删除会话时删除按钮禁用（操作中）。

## 11. 加载骨架与过渡

### 11.1 骨架屏

| 区域 | 骨架内容 |
| --- | --- |
| 消息列表（首次加载） | 3～5 条不同宽度的灰色条，模拟消息左右分布 |
| 话题面板 | 2～3 条标题 + 简短描述灰色条 |
| Agent 面板 | Agent 头像占位 + 2 条决策条目骨架 |
| 快照面板 | 3～4 条条目骨架 |
| 模型调用面板 | 3～4 条条目骨架 |

### 11.2 过渡动画

- 新消息气泡：轻微淡入（~200ms），不平移或弹跳。
- SSE 事件触发的分析区更新：内容直接替换，不带动画。
- 标签切换：即时切换，无滑动过渡。
- 停止按钮状态变化：颜色过渡 ~150ms。
- 生成指示器脉冲点：CSS animation，~1s 循环。

## 12. 验收说明

### 12.1 验收场景

| # | 场景 | 验收标准 |
| --- | --- | --- |
| 1 | 发送消息 → 双 Agent 接力 | 聊天区显示消息 → 生成指示器 → Agent 回复 → 状态栏更新 |
| 2 | Agent 沉默 | 某轮无 Agent 回应，状态栏显示"无人需要回应"，接力结束 |
| 3 | 两 Agent 都想回应 | 高分者发言，低分者显示"想回应但未选中"（eligible_not_selected） |
| 4 | 硬资格排除 | 连续发言 2 次的 Agent 标记 `ineligible`，不参与本轮 |
| 5 | A → B → A | 话题面板展示完整转换链，快照显示恢复时的上下文摘要 |
| 6 | 用户停止接力 | 停止按钮 → 停止请求 → 停止完成，无新消息产生 |
| 7 | 模型调用失败 | 系统消息提示失败，模型调用面板显示错误，文本框恢复 |
| 8 | SSE 断线重连 | 重连后补齐事件，两区状态一致，无重复或遗漏消息 |
| 9 | 刷新后历史只读 | 消息完整，分析区数据一致，不能发送新消息到旧运行（新建会话发送） |
| 10 | 窄屏自适应 | 900px 以下切换标签布局，两区功能完整 |
| 11 | 键盘导航 | 仅使用键盘完成发送、停止、切换标签、浏览消息和分析 |
| 12 | 空状态 | 新建会话各区域显示对应空状态提示 |
| 13 | 运行中超限 | 达到上限后自动停止，状态栏显示终止原因和计数 |
| 14 | 服务重启恢复 | 重启后遗留运行标记为 failed，历史可读可复盘 |

### 12.2 不验收场景

以下场景经产品确认不属于首版验收范围：

- 逐 Token 流式显示生成文本（首版采用"一次性显示完整回复"）。
- 通用话题编辑器与人工修正 UI（仅保留分析区观察误分类的能力）。
- 多会话并行运行与切换。
- 移动端原生手势（滑动返回等）。
- 深色模式。
- 国际化与多语言。

## 14. 与架构契约的一致性

本规范以下方面与 `docs/architecture.md` 保持一致：

| 架构决策 | UX 规范的对应 |
| --- | --- |
| REST + SSE（非 WebSocket） | 消息发送通过 REST（接受 202），状态更新通过 SSE 事件流 |
| 先提交再通知 | 聊天区状态仅来自 SSE 事件，不来自前端超时猜测 |
| 沉默是一等结果 | 分析区显示 silent/eligible_not_selected/ineligible 三种非发言状态 |
| 单 active 话题 | 话题面板始终只有一个 active 标签 |
| 双决策屏障、单发言者 | Agent 面板显示两人的决策，但聊天区只有选中者发言 |
| 不可变快照 | 快照面板展示只读快照，无编辑操作 |
| 分析区不展示隐藏推理 | 原因仅来自结构化维度和原因码 |
| 无通用话题编辑器 P0 | 分析区保留观察误分类的能力，不提供编辑 UI |
